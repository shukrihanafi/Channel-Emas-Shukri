# Channel Emas (separa-auto)
Bot ambil harga Public Gold, siapkan post Malay + imej, hantar ke Telegram. Anda forward ke WhatsApp Channel.

Jadual (waktu Malaysia): 9:00 pagi GAP, 12:30 PG Jewel, 8:00 malam Ilmu Emas, setiap 30 min (9 pagi-10 malam) semak Price Alert.
Ubah ambang alert: `ALERT_THRESHOLD` dalam `.github/workflows/channel.yml` (RM).
Tambah ilmu emas: `data/ilmu.json`. Tambah item PG Mall: `data/items.json` (nama, harga, link, imej).
